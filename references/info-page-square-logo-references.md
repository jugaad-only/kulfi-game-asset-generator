# Info-Page Square Logo References

Read this file when the corresponding `daily_game_icon` is approved and before creating `daily_games_info_page_square_logos`. This asset does not depend on the partner-turn or completed-state derivative.

## Direction

- Use a 1024 x 1024 WebP canvas unless the project specifies another target.
- Treat the approved daily icon as the source of truth for the game symbol, silhouette, monochrome color family, felt material, and positive/negative space.
- Center the symbol on a pale background from the same monochrome color family.
- Preserve generous, visually even breathing room around the symbol; keep it safely inside the square crop.
- Keep the felt symbol darker or more saturated than the background so it remains legible without introducing a second dominant hue.
- Do not include the game title, promotional copy, logo lockup, watermark, or readable UI label. A mechanic-critical letter or mark is allowed only when it is part of the approved game symbol.
- These references define the square-logo composition system; do not copy another game's symbol for a new game.

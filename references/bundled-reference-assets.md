# Bundled Reference Assets

This skill package is link-first and includes a compact offline fallback so colleagues can work without the original project workspace. Read `cdn-reference-manifest.md` before selecting references; live CDN inventory includes legacy and game-specific outliers that are not valid general house-style examples.

Use these assets as visual family references only. Do not copy another game's exact symbol, board state, prop arrangement, or subject for a new game. For game-specific work, the approved current-game asset and verified mechanic remain the source of truth.

## Reference Folders

- `assets/style-references/kulfi-approved-thumbnail-study-sheet.png` - quick thumbnail shelf-style overview.
- `assets/style-references/approved-thumbnails-3x4/` - curated portrait fallback references, not the full CDN inventory.
- `assets/style-references/approved-thumbnails-16x9/` - curated landscape fallback references, not the full CDN inventory.
- `assets/style-references/approved-daily-game-icons/` - approved daily game icon references.
- `assets/style-references/approved-partner-turn-icons/` - approved partner-turn icon SVG/WebP references.
- `assets/style-references/approved-info-page-square-logos/` - approved info-page square logo references.
- `assets/style-references/approved-completed-banners/` - approved completed-state banner references.
- `assets/style-references/approved-your-turn-backgrounds/` - approved your-turn background references.

## How To Choose References

- For a new 3:4 thumbnail, use the contact sheet plus 3-5 `accepted` references from the local fallback or CDN manifest.
- For a 16:9 thumbnail, use the approved 3:4 source plus 3-5 `accepted` landscape references from the local fallback or CDN manifest.
- For a `daily_game_icon`, use the approved thumbnail plus `approved-daily-game-icons/`.
- For a partner-turn icon, use the approved daily icon plus `approved-partner-turn-icons/`.
- For an info-page square logo, use the approved daily icon plus `approved-info-page-square-logos/`.
- For a completed-state banner, use the approved daily icon plus `approved-completed-banners/`; still ignore Hangman as a completed-state style reference where the completed-state guide says to.
- For a your-turn background, use the approved daily icon plus `approved-your-turn-backgrounds/`.

Do not use `same-game-only` references for unrelated games. Never use a `rejected` reference for generation or QA.

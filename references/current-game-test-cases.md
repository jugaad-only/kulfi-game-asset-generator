# Current Game Test Cases

Use these for dry-run prompt testing before a new final game. They are not final prompts; they are fixtures to check whether the skill preserves rules across game types.

## Wordle

- Mechanic: guess words on a tile grid with color feedback.
- Visual cues: chunky square letter tiles, green/yellow/gray feedback, clean word-board layout.
- Mood: satisfying, smart, quick.
- Risk: invalid word state, title text, cluttered tiny letters.

## This Or That

- Mechanic: choose between two options.
- Visual cues: two opposing option cards, simple divider or `OR` token only if it is a game object rather than title copy, playful food or lifestyle props.
- Mood: social, funny, debate-friendly.
- Risk: text-heavy choice cards or unclear binary contrast.

## Snatch the Fries

- Mechanic: steal or pull fries.
- Visual cues: red fries bucket, golden fries, cyan kitchen backdrop, magnet/snatch motion.
- Mood: fast, cheeky, arcade.
- Risk: bottom-left clutter, fries bucket too small, title text.

## Moodoku

- Mechanic: sudoku-like placement puzzle with mood/color language.
- Visual cues: clean grid, separated cells, rule-accurate tile placement, soft bright color coding.
- Mood: calm, clever, tactile.
- Risk: board logic wrong or decorative grid overwhelms the focal subject.

## Pillowtalk Legacy

- Mechanic: intimate conversation or prompt exchange.
- Visual cues: two plush pillows, speech-bubble/card cue without readable text, cozy fabric, soft room colors.
- Mood: cozy, warm, private.
- Risk: text labels, too much bedroom realism, subject too small.

## Sperm Racers

- Mechanic: race through a maze toward an egg.
- Visual cues: dark maroon tunnel, rose-pink maze walls, mint route, gold egg glow, playful abstract race forms.
- Mood: competitive, silly, arcade.
- Risk: anatomical realism, wrong palette, cinematic darkness, unclear race path.

## Weave

- Mechanic: must be verified from the actual game source, gameplay screenshot, Figma frame, or user explanation before generation.
- Visual cues: use existing approved Weave asset only for style/material language, not as proof of the full rule system.
- Mood: cozy, clever, satisfying.
- Risk: polished board/path art that does not obey the real game mechanism or rules.

## Chess

- Mechanic: move rule-accurate pieces to threaten or check the opposing king.
- Visual cues: recognizable king and knight silhouettes, honest board geometry, one focused tactical confrontation.
- Mood: strategic, competitive, premium.
- Risk: impossible board state, generic medieval poster art, title text.

## Ludo

- Mechanic: race colored tokens from home around a cross-shaped board toward the finish.
- Visual cues: chunky colored pawns, recognizable cross-board route, one clear race interaction.
- Mood: social, bright, competitive.
- Risk: incorrect board routing, too many equal focal points, bottom-left clutter.

## Jigsaw

- Mechanic: assemble interlocking pieces to complete one picture.
- Visual cues: large tactile puzzle pieces, one obvious placement gap, partial image reveal.
- Mood: calm, satisfying, crafty.
- Risk: a completed illustration with no puzzle action, tiny scattered pieces, fake logo text.
